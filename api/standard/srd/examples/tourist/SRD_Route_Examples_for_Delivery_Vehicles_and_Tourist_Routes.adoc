==== What to notice

* Route-level actions set the whole trip: a helmet briefing, a heat warning and a default speed limit of 25 km/h. Segments override the speed limit (20 km/h in the operator zone, 15 km/h on the shared path); each is reverted to 25 km/h at the segment end.
* The input has four places to visit. The server chose the means of travel per segment (`travelMode`: `escooter`, `walk`, `ebike`) and *inserted two transfer points* (Piazza San Carlo, Piazza Vittorio bike station). `tour.switch-vehicle` (composite) ends the scooter trip; the e-bike section uses the explicit sequence `tour.find-vehicle`, `tour.unlock-vehicle`, `tour.set-assist-level`.
* `tour.set-assist-level` on the climb and descent are segment actions, so the e-bike returns to the previous level after each.
* Palazzo Reale has a `noEarlierThan` constraint (opening time). The definition has a `doNotLeave` tour area.
* The only target is the traveller (pseudonymous URI).
